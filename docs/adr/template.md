# NNNN — The decision, stated as a decision rather than as a problem

**Status:** `Proposed`, or `Accepted`, or the words `Superseded by` followed by a Markdown link
to the record that replaced it

**Decided:** YYYY-MM-DD

**Evidence:** the pull request, build or file where this is visible

## Context

What was true when the decision was made, and what forced a choice. Constraints belong here,
including the ones that are not technical. Write it in the past tense and do not update it
later — a record describes a moment.

## Options considered

Each one named, with the reason it was not taken. An option listed without a reason is
decoration, and an option that was never actually available is not an option.

## Decision

What was chosen. If it was chosen with low confidence, say so here: a decision taken on thin
evidence is worth revisiting, and this file is the only thing that will remember it was thin.

## Consequences

What this made easy, what it made hard, and what it cost. **At least one consequence must be a
cost actually paid.** A record whose consequences are all benefits is a justification rather
than a record, which is the failure mode of writing these after the fact.
